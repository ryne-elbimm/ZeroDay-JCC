# Sanity Check — Misc

## 📌 Deskripsi

Challenge **Sanity Check** merupakan challenge kategori **Miscellaneous (Misc)** pada Jatim Cybersecurity Competition 2026.

Peserta diberikan soal berupa ucapan selamat datang di Jatim Cybersecurity Competition 2026 dan diminta untuk menemukan flag yang terdapat di dalam **PDF Petunjuk Teknis**.

## 🔎 Penyelesaian

### 1. Membuka File

Pertama, buka file yang diberikan melalui Discord.

### 2. Mencari Petunjuk

Setelah file dibuka, cari bagian yang berisi petunjuk atau flag yang tersembunyi di dalam dokumen.

Setelah petunjuk ditemukan, teks tersebut dapat disalin secara manual atau menggunakan **Google Lens** untuk mempermudah proses pembacaan dan penyalinan teks.

### 3. Mendapatkan Flag

Setelah teks berhasil ditemukan dan disalin, flag dapat langsung digunakan untuk menjawab challenge.

## 🧠 Konsep yang Dipelajari

* Document analysis
* Information gathering
* Text extraction
* Pemanfaatan OCR untuk membantu membaca teks
